# robotPathPlanners

This project is a **MATLAB application** designed to demonstrate mobile robot path planning algorithms. It features an interactive Graphical User Interface (GUI) that allows users to visualize how different search algorithms explore grid-based environments, avoid obstacles and compute optimal routes.
